# Imperative Programming

This repository contains my own code written while taking the **DSNSWCB105 Imperative Programming** course at Aalborg University (AAU).

The programs were created by me based on coursework assignments, exercises, and problems from the module.

The course focused on fundamental imperative programming concepts using **C**.

Files starting with `exam-` are programs based on tasks that could be drawn during the exam.

This was my favorite course, and I achieved the **highest possible grade**.
